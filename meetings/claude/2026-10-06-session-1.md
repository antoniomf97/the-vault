2. **The opening paragraph is the model in six sentences; then four parts that mirror the review.** Each part states what is fixed, what is varied and by which question. What is held fixed is the limitation.
3. **Two levels, never mixed: the action and the profile.** What is set from outside is the agents' *profile*. Their *actions* change all the time, because that is what a heuristic or deliberative profile does. "Who copies whom" is said once for actions and once for profiles.
4. **What is new for agents is conformity and aspiration (heuristic), counterfactual thinking and theory of mind (deliberative).** The gap says "beyond imitation and reinforcement learning", and [[jiaAsymmetricInteractionPreference2025|Jia2025]] already has imitating agents. Fixed and imitating agents stay as the cases that must reproduce known results. All agents carry one profile in a run (Toino's), which is what makes the profile the thing compared.
5. **Identity is three lines:** kind is fixed; kind is visible to all; hidden or mistaken identity and bias against agents are left out. The review shows people do treat agents differently ([[ishowo-olokoBehaviouralEvidenceTransparency2019|Ishowo-Oloko2019]], [[jiangHumansLearnPrefer2025|Jiang2025]], [[barreda-tarrazonaExploitingMachineHuman2026|Barreda-Tarrazona2026]]), so it is a named limitation. How the knowledge of kind is *used* is specified where it is used: matching, role models, action.
6. **Whether a partner's kind affects the action is part of the profile** (Toino moved it to agent design; he was right). Fixed and heuristic profiles play the same action against everyone, as every model compared against assumes. Deliberative profiles may use the kind to predict the partner's move.
7. **Knowledge (agents global, humans local) is an attribute of the kind** (Toino's; I had filed it under agent design). Whether to assume it at all is separate. No model in the review does, so it needs a one-sentence definition (what exactly an agent knows that a human doesn't), a control run (same profile, local knowledge) and a check that it can matter: in a well-mixed population a human's own encounters are already a fair sample, so it bites only when assortment biases what humans see.
8. **Reasoning cost differs by kind** (Toino's, and the best new assumption in the draft). If deliberating is free, nothing stops everyone from deliberating; in Bear2016 it is selected only when it pays more than it costs.
9. **Where the humans' distribution over profiles comes from** (the standing question):
    - RQ1: all humans use payoff-based imitation. Assumed, to stay comparable with every model validated against.
    - RQ2: the distribution is the result, not an input. Start from several mixes (Toino's 50/40/10, all imitators, equal thirds, mostly deliberative) and report where each ends.
    - Say whether humans can switch profile at random. With a little random switching a finite population forgets its start in the long run; without it the start can decide the outcome.
    - Experiments check the output; they don't set the input. There is evidence for the categories, none for any percentages (see Reading).
10. **Assortment is one axis**, from homophily through well-mixed to heterophily, so one parameter (as in the 29 Sep notes; Toino restated it on 6 Oct).
11. **One game for both kinds; what can differ is the agent's objective.** Toino's instinct ("AI tends to be more cooperative", asymmetric games) points at a real hole: the sheet never said what an agent is trying to achieve. Proposal: one parameter, the weight an agent puts on its partner's payoff, as in [[guoEngineeringOptimalCooperation2024|Guo2024]]. Both kinds are paid from the same matrix; the weight changes only how the agent chooses. In the terms of 28 Sep: same objective game, different subjective game. **Not adopted**: Toino is unsure, so it went to the meeting as an option.
12. **Theory of mind: depth capped at two levels, and a prediction that can fail.** Toino's argument: in one symmetric two-action game, reasoning deeper than a step or two adds nothing, so a single game is too simple to show whether theory of mind pays. Agreed on the problem; the review says the same (Qi2022, Kimbrough2013). His proposed test (the same game against different games) becomes weight zero against weight above zero. At zero, theory of mind should add nothing, which is a validation. Above zero it can pay.

### The agent's objective: the example

With 3 for mutual cooperation, 5 and 0 when one defects and 1 for mutual defection, an agent that counts its own payoff plus *w* times its partner's:

- against a cooperator gets 3 + 3*w* for cooperating and 5 for defecting, so it cooperates above *w* = 2/3;
- against a defector gets 5*w* for cooperating and 1 + *w* for defecting, so it cooperates above *w* = 1/4 (not said in session);
- between 1/4 and 2/3 its best move therefore depends on its partner's, which is where predicting the partner starts to matter;
- is paid 3, 5, 0 or 1 whatever it chooses, like everyone else.

A human is the case *w* = 0. The thresholds hold for these four numbers only.
